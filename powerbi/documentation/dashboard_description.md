# Power BI Dashboard Documentation


## Overview

Implemented Power BI reporting layer connected to Azure Synapse Serverless SQL views.

The dashboard provides claims analytics visibility using data prepared from the Gold layer.


## Data Source

Azure Synapse Serverless SQL Pool


Reporting View:

dbo.claim_dashboard


## Claims Dashboard

Purpose:

Provides business insights into insurance claim performance.


## Visualizations

### Total Claims by Year

Shows yearly claim volume trends.


### Total Claims by fraud_flag

Shows analysis of total claims based on fraud.


### Total Claims by State

Shows distribution of claims based on state.


### Total Claim Amount by Category

Shows total claim amount per each category
